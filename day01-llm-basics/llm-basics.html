第 1 节 · 大模型基础认知

不背定义，用代码把 LLM 的几个核心概念跑一遍。所有示例都支持离线 Mock（无需 key），配置 OPENAI_API_KEY 后自动走真实模型。

一句话核心：大模型本质上是一个 “下一个 token 预测器”——给它前文，它算出概率最高的下一个 token，接上去，再预测下一个，如此循环，直到说完。06_tiny_predictor.py 用几十行代码把这个机制从零复现了一遍。

00 · 一次最小调用

一次对话补全返回的对象里，最该记住三个字段：content（说了啥）、usage（花了多少 token）、finish_reason（为什么停）。

from llm_client import get_client
client, _ = get_client()
resp = client.create(
    messages=[{"role":"user","content":"用一句话解释什么是 token"}],
    temperature=0.2,
)
print(resp.choices[0].message.content)   # 模型说了啥
print(resp.usage.total_tokens)           # 花了多少 token
print(resp.choices[0].finish_reason)     # stop=正常 / length=被截断
回答： token 是模型处理文本时的最小单元... 用量： {'prompt_tokens': 18, 'completion_tokens': 42, 'total_tokens': 60} 结束原因： stop

01 · Token 与成本

Token 是模型处理与计费的最小单元。同一段文字，英文近似“词”、中文近似“字”、代码因符号多而更碎——所以同样的预算，中文能处理的字数明显少于英文。

from llm_client import approx_tokens
print(approx_tokens("Token 是大模型处理文本时的最小单元。"))   # CJK 每字≈1 token

装了 tiktoken 能看到真实切分（enc.encode(text) 返回 token id 列表）；没装则退化为估算，仅作量级参考。

02 · 上下文窗口与截断

两个上限要分清：max_tokens 是单次回答的生成上限（触顶则 finish_reason=length 被截断）；Context Window 是输入+输出的总 token 上限（超了要么报错，要么丢弃最早的历史）。

返回内容： ...（只生成了 20 token 就被掐断） 结束原因： length

03 · Temperature

温度控制随机性：接近 0 每次输出稳定、可复现（适合 JSON、分类、抽取）；接近 1 发散、有创意（适合头脑风暴、文案）。

run_at(0.0, 3)   # 三次几乎一致
run_at(1.2, 3)   # 三次各不相同

04 · 流式输出

stream=True 让首字延迟极低：用户边想边出，是大模型产品的标配体验。真实与 Mock 都支持，Mock 按字符逐个 yield。

05 · 结构化输出

模型默认吐自然语言，代码难直接用。用 JSON Mode（或 Function Calling）拿到结构化结果，Agent 才能把模型输出接进代码逻辑——这正是后面 Function Calling 章节的铺垫。

content = '{"name": "通义千问", "type": "对话大模型", "feature": "阿里发布"}'
data = json.loads(content)   # 自然语言 → 可程序消费的对象

06 · 从零实现“下一个字预测器”（重点）

不需要任何大模型、不需要联网。在一小段文本上统计「每个字后面最常跟哪个字」，就得到一个最简单的语言模型。GPT 做的事与下面完全同源，只是它用上亿参数的 Transformer、在万亿 token 上训练，把“概率”估得准得多。

def build_model(text):
    counts = defaultdict(Counter)
    for i in range(len(text)-1):
        counts[text[i]][text[i+1]] += 1        # 统计 (前字 -> 后字)
    return {a: {b: n/sum(c.values()) for b,n in c.items()}
            for a, c in counts.items()}         # 转成概率分布

def generate(model, seed, length=25, temperature=1.0):
    cur = seed[-1]
    for _ in range(length):
        dist = model[cur]
        nxt = max(dist, key=dist.get) if temperature<=0.01 \
              else random.choices(list(dist), weights=dist.values())[0]
        seed += nxt; cur = nxt
    return seed
演示 1：给定前文「大」，下一个字的概率分布 → '模': 100.00% 演示 2：从「大」接龙（temperature=0）→ 大模型在猜下一个字。大模型不懂语言...（固定） 演示 3：从「大」接龙（temperature=1.5）→ 分叉处随机，更发散 核心结论：上面的“接龙”和 GPT 是同一件事。
